# Evaluation / Progress Measurement Research

> Research for ticket #010 — how to objectively measure a learner's progress in FALA.

## Approaches from existing tools

| Tool | Metric | How it works | Suits FALA? |
|------|--------|-------------|-------------|
| **Duolingo** | Duolingo Score (0–160) + CEFR bands | IRT + ML estimates ability from every practice response | ❌ Overkill — needs large item bank and adaptive testing infrastructure |
| **Anki** | Mature retention % + interval growth | FSRS/SM-2 schedules cards; interval = progress | ✅ **Already have this** — SM-2 in `progress.py` |
| **LingQ** | Known Words count | Words marked status 4 (Learned/Known) = total vocabulary | ✅ Simple, aligns with SRS data |
| **CEFR mapping** | % vocab at A1/A2/B1 levels | Frequency-ranked word list → heuristic CEFR bands | ✅ Feasible with pt_50k.txt |

## What FALA already has

| Data point | Source | Currently used? |
|------------|--------|-----------------|
| Words per session count | `end_session()` | ✅ Shown at session end |
| SRS confidence (0.0–1.0) | `progress.py` | ✅ Internal, not shown |
| Interval (days until next review) | `progress.py` | ✅ Internal, not shown |
| Session history | `data/sessions/` | ✅ Raw logs, unanalysed |
| Vocabulary growth over time | `data/vocabulary.md` | ✅ Persistent, no trend view |
| Learning records (graduated words) | `data/records/` | ✅ Created on confidence ≥ 0.8, no summary |

## Recommendation

**Add three lightweight progress indicators — no new data collection, no external APIs.**

### 1. CEFR-graded vocabulary dashboard
- Use [`pt_50k.txt`](https://github.com/hermitdave/FrequencyWords) (~50K words, MIT license) as the frequency base
- Heuristic CEFR bands: top 500 = A1, 500–2000 = A2, 2000–5000 = B1, 5000+ = B2+
- Display at session end: `Vocabulary: 45 words (A1: 30 · A2: 12 · B1: 3)`
- No network needed — load the flat file at startup

### 2. SRS health report
- Show retention rate (how many reviews were correct vs. incorrect this session)
- Show mature word count (words with confidence ≥ 0.7)
- Track trend across sessions (compare to previous session's retention)

### 3. Weekly trend summary
- Read session logs to find: longest streak, most improved area, words still struggling
- Could be generated by the LLM at end of session (already does a summary)
- Show as a "7-day recap" when requested
